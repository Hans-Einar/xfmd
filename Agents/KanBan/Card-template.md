This is a template, not a registered card. Create the card and ledger event
together. Status follows directory/ledger; do not duplicate it in frontmatter.

## Need and source

What should be remembered? Separate owner instructions from recommendations and
recollections. Include enough context to resume without the chat transcript.

## Findings, proposal and open questions

State evidence, branch/commit, scope, affected projects and unknowns. For a synthesis,
add a source table with retained/superseded information and unresolved remainder.
For a Ref, name and link the existing primary card.

## Next review and completion criteria

State what needs deciding/delivering. For active work, add owner, bounded scope and
checks. For onHold, add reason/resumption trigger. Recording is not approval.

## Outcome and references

Record actual outcome, decision/delivery/evidence, successors and limitations.
Closing a discussion is not evidence of product implementation.
