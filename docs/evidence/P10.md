# P10 — Preferences og scrolling

## P10-M1 — Uttrekk

ScrollDynamics eier nå rest og clamped mål, uten FOX-avhengighet. Adapteren
normaliserer code/120 og beholder eksisterende timer under kompatibilitetssteget.
Review fant en manglende direkte cstdint-include etter uttrekket; rettet før
bestått bygg. Flyttallsavrunding nær heltall får toleranse 1e-10 slik at tolv
1/120-inkrementer med unit=10 faktisk gir én pixel.

ScrollMotionTest, WheelGuiTest og WorkPathGuiTest verifiserer smådeltaer,
endepunkter, reversering, native input og historikk. GUI-testene kjører isolert.

## P10-M2 — Preferences

Edit → Preferences er koblet til én PreferencesService, med isolert EditorWidget-
prøvefelt. Hastighet lagres i applikasjonens registry og publiseres til hele
widgettreet etter suksess. Akselerasjonskontrollene kobles til dynamikken i M3.
PreferencesTest verifiserer draft/cancel, NaN, roundtrip, bevaring av ukjente
felter/WorkPaths, native dialogkonstruksjon og rollback i minnet etter skrivefeil.
Nyere schema avvises for skriving. WorkspaceTest og ScrollMotionTest består også.
Review: ingen endring i dokument/undo; butikkens rollback hindrer at feilet draft
blir lagret ved senere app-exit. A4-marger er lagret for P11-integrasjon.
