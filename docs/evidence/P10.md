# P10 — Preferences og scrolling

## P10-M1 — Uttrekk

ScrollDynamics eier nå rest og clamped mål, uten FOX-avhengighet. Adapteren
normaliserer code/120 og beholder eksisterende timer under kompatibilitetssteget.
Review fant en manglende direkte cstdint-include etter uttrekket; rettet før
bestått bygg. Flyttallsavrunding nær heltall får toleranse 1e-10 slik at tolv
1/120-inkrementer med unit=10 faktisk gir én pixel.

ScrollMotionTest, WheelGuiTest og WorkPathGuiTest verifiserer smådeltaer,
endepunkter, reversering, native input og historikk. GUI-testene kjører isolert.
