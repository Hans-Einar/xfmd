# P2 — dokument og FOX-arbeidsflate

M1: Implementert dokumentøkt, dirty-transaksjoner, UTF-8/inputpolicy, tapsfri
editorprojeksjon, undo/redo og atomisk filpublisering med metadata/konfliktkontroll.
M2: Implementert FOX-vindu, menyer, toolbar, kommandoer, sidepanel, view modes,
søk, filvalg, save/save-as og dirty-dialog. Standard preview blir fylt i P3.

Bevis: Debug-build med GCC 14.3.1/FOX 1.6.57 og
`ctest --test-dir build --output-on-failure`: fem tester passerer, inkludert
DocumentTest og WorkspaceTest under isolert Xvfb. Testene dekker blant annet
BOM/CRLF/Unicode, metadata, ekstern endring, før-rename-feil, hardlinks, ny-fil-
identitet, undo til baseline, filter og ekte FXText endringsmeldinger.

Ingen nye testframework-dependencies. Funksjonalitetsdokumentene 001/002/010/011
har oppdatert plumbing til faktiske symboler. Preview, scroll og historikk står
fortsatt i etterfølgende faser; P2 er ikke påstått komplett viewer.
