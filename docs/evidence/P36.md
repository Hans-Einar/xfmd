## Reproduksjon

Vanlig README-bootstrap og låst Cargo/CMake-bygg brukes. Etter bootstrap kan
bygg og tester kjøres offline; programmet bruker ingen Mermaid-prosess eller nett.

```sh
cmake --build build -j2
XFMD_DIAGRAM_EVIDENCE="$PWD/docs/evidence/P36" ctest --test-dir build -R 'Diagram|Mermaid' --output-on-failure
build/MermaidPdfFixture docs/evidence/P36/mixed.pdf /tmp/p36-labels.txt
python3 tools/validate_blueprints.py
python3 tools/check_blueprint_symbols.py
```

## Kjente avgrensninger

Dette er ikke full sequence-kompatibilitet. Async-piler, nested fragmenter,
notater/aktivering inne i fragmenter og tvetydige notatgrenser avvises eksplisitt.
De krever neste sekvensinkrement før state/class/requirement/ER åpnes.
Ingen guard, scheduling, SDL-typekontroll eller verifikasjonsrelasjon evalueres.
Sekvensens SVG-scene har ikke fiktive flowchart-inspeksjonsobjekter; etikettmerking
i GUI er fortsatt utsatt. Lange diagrammer skaleres samlet til én PDF-side og
bør deles av forfatteren når tekst blir liten. Fristen er kooperativ.

Full sanitizer-/plattformmatrise er ikke gjentatt i denne fasen. Bygget er lokalt;
ingen merge eller utskifting av brukerens kjørende/installert program er utført.
