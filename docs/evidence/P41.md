## Reprodusering

```sh
cmake --build build -j2
ctest --test-dir build --output-on-failure -j2
python3 tools/check_mermaid_pdf.py build/MermaidPdfFixture mermaid_evicence.md
python3 tools/validate_blueprints.py
python3 tools/check_blueprint_symbols.py
cd build
./xfmd ../mermaid_evicence.md
```

`XFMD_DIAGRAM_EVIDENCE=$PWD/docs/evidence/p41-mermaid-coverage` foran CTest
skriver de vedlagte SVG- og lys/mørk-PNG-filene. En permanent PDF lages med
`build/MermaidPdfFixture docs/evidence/p41-mermaid-coverage/gallery.pdf /tmp/xfmd-gallery-labels.txt mermaid_evicence.md`.
Bygging og avhengighetsoppsett følger README; kjøring/layout krever ikke nettverk,
Node eller nettleser. Eksisterende installert XFMD er ikke erstattet.

## Verifikasjon

Forkens sluttkontroll: 419 tester bestått (398 bibliotek, 12 libavoid, tre
planning, tre semantic og tre chart geometry). Currentness kjørte 24 ganger.
Blueprint-kontroll: 35 objekter / 65 krav, 234 navngitte Implemented-callees.
Dette er struktur-/symbolkontroll, ikke bevis for faktisk C++-kallgraf.

XFMD Release på sluttpinnen: **59/59 CTests bestått på 90,68 sekunder**,
inkludert 25 isolerte GUI-tester. [CTest-logg](p41-mermaid-coverage/ctest.txt) og
[fork-logg](p41-mermaid-coverage/fork-tests.txt) følger med. Galleriet eksporterer
29 scener / 23 familier til **22 A4-sider**, uten rasterbilder; alle forventede
etiketter og Unicode-tekster er bevart. Den separate `check_mermaid_pdf.py`-
kommandoen er også kjørt med selve gallerifilen og bestått.

Testene dekker parseravvisning, typed wire-roundtrip, geometri, eksisterende
flowcharts, blandet Markdown, frister/feilveier, faktisk Cairo/librsvg-preview og
vektor-PDF. DiagramReadingTest maler alle nye fixtures ved 75/100/150 prosent
skalering i lys og mørk palett; layout ved bredde 320/900 bevarer sideforhold.
Dette er automatisert maling med samme Cairo-transformasjon som FOX, ikke en
påstand om manuell testing av alle vindusstørrelser og skjermer.

32 diagrammer inngår i standard PDF-fixture. Den separate galleritesten krever
nøyaktig 29 scener og 23 bevarte familier. PDF-tekstkontrollen bruker både spatial
og content-stream-rekkefølge fordi parallelle ombrutte etiketter flettes i
spatialt uttrekk. Markdown kontrolleres som tegnede runs, slik at dekorative
linkprefikser ikke feilaktig tolkes som mistet avsnittstekst.

## Visuell kontroll og rettelser

[Faktiske SVG/PNG/PDF-artefakter](p41-mermaid-coverage/). Lys/mørk presentasjon er
inspisert for de nye familiene; særlig Sankey, Kanban, Quadrant, Gantt, GitGraph
og Packet er kontrollert etter polering. PDF-sider med Class, Radar, Sankey og Quadrant er også
rasterisert og lest. Tidligere fasebevis dekker sekvens og semantiske grunnprofiler.

- Sankey reserverer målte caption-bredder og tegner tekst etter bånd. Etiketter
  beholder eget bånds sentrum når det er plass, fremfor å pakkes mot naboetiketten.
- Kanban skiller kolonneoverskrift fra første kort; Quadrant akser og bakgrunner
  følger mørk palett. Gantt-tittel bruker faktisk teksthøyde.
- GitGraph beholder LR-retning og branchens checkout-semantikk. Packet bruker
  ekte bitbredder og rader; Block-pilspisser treffer boksgrensen.
- Små state-pseudonoder registrerer ikke identiske eksklusive porter flere ganger.
  Currentness-fixturen testes med 24 gjentatte layouter.

## Kjente grenser

Avgrensede profiler er ikke full Mermaid-kompatibilitet. Ukjente konstruksjoner
skal gi synlig kildefallback. Ruting med konkurrerende porter kan variere;
byteidentisk SVG loves ikke. Composite state og C4 har enklere native ruting.
Store diagrammer kan bli små på A4; SVG-tekst er ikke separat markerbar i preview.
Diagramfamilienes native kategorifarger beholdes der fargen bærer betydning.
Ingen ny sanitizer-kjøring eller CI-resultat påstås i dette fasebeviset.
