# P4 — revisjonssikker live preview

M1: FOX scheduler, 300 ms debounce og bounded parser-worker er implementert.
Én aktiv jobb pluss én erstattbar pending jobb; gamle completions publiseres ikke.
GUI-tråden eier fortsatt fontmåling, layout og paint. Parsefeil blir typet status.
M2: deterministiske tids-/arbeider-/teardown-tester og ekte FOX-live-preview er verifisert.

`cmake --build build --parallel 4` og `ctest --test-dir build --output-on-failure`:
ni tester passerer. PreviewTest bruker fake clock og en kontrollert blokkert parser:
0/100/250 ms → første jobb ved 550 ms; superseded pending jobb kjøres ikke; resize
reparser ikke; parsefeil viser ikke ny feilaktig frame. Metrics bekrefter GUI-tråd.
PresentationTest bekrefter oppdatering fra ekte FXText-event via FOX-timer og
bevaring av fokus/cursor. Destructor cancellerer timere før worker join/FOX-teardown.

Lagre som .txt/.md oppdaterer semantisk revisjon ved formatbytte, selv om bytes er
uendret. Full benchmark av parse+layout og RSS gjenstår til P7.
