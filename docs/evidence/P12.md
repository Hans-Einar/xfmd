# P12 — PDF-eksport

## P12-M1: Frosset jobb

FUNC-018 / UR-018 / SR-017. ExportCoordinator eier én joinbar worker,
kopierte inputs og atomisk status. Arbeidsfunksjonen injiseres; ingen FOX-kall
eller konkrete parser-/renderer-avhengigheter i koordinatoren. Cancel og commit
har en felles mutex som definerer publiseringsøyeblikket.

ExportJobTest dekker endring/bytte av kilden etter start, avvist parallelljobb,
feil, cancel og shutdown. Review: result publiseres med release/acquire før join;
destruktor kansellerer og joiner før eide data destrueres.

## P12-M2: Transaksjonell PDF og brukerflate

File → Export PDF (Ctrl+Shift+E) fryser gjeldende buffer og viser framdrift;
File → Cancel PDF export avbryter. Worker bygger egne parser/fontinstanser.
Paged frame gjenbrukes bare ved riktig token/papir/fontsett; ellers bygges det
via de samme offentlige portene. DisplayListPainter utfører begge outputmål.

Søskentemp er privat (0600); eksisterende mål beholder POSIX-modus ved erstatning.
Symlinks/hardlinks avvises. fsync og målidentitet kontrolleres før atomisk
publisering; ingen markSaved. Ekstern skriving mellom siste identitetssjekk og
rename har samme begrensning som LocalFileStore. Katalog-fsync er best effort;
ingen garanti mot strømbrudd på filsystem som ikke støtter den. Eksport bevarer
ikke eksisterende PDF-eierskap/utvidede attributter; den lager et nytt dokument.

8/8 målrettede CTest-kontroller bestod: ExportJobTest, PdfExportTest,
ExportGuiTest, TypographyTest, PageLayoutTest og tre design-/lagkontroller.
Ekte /dev/full avviser Cairo-skriving; målkonflikt, avbrudd, samtidig opprettelse,
fontsettendring og temp-opprydding er kontrollert. Native test redigerer mens
GUI-eksport kjører og bekrefter dirty/undo og status med eksportert revisjon.
