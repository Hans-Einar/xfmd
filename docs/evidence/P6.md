# P6 — lokale dokumentreiser

M1: LinkResolver, HistoryStore og NavigationCoordinator er implementert. Alle åpne-
innganger bruker samme dirty-/I/O-transaksjon; opened-callback committer historikk
én gang etter suksess. Historikk er 100 poster med cursor, ikke FIFO.
M2: headless scenarioer og ekte FOX-host-hit→filbytte→back/forward er verifisert.

`cmake --build build --parallel 4`; `ctest --test-dir build --output-on-failure`:
tretten tester passerer. NavigationTest dekker A/B/C/back/D, failed open, dirty-cancel,
percent decoding, ugyldige URI-schemes, fragmenter, gren-trunkering og grense.
NavigationGuiTest aktiverer rendererens faktiske lenkeregion og sjekker dokument,
historikk og tilbake/frem etter nye frames. Ingen ekstra preview/parser er laget.

Filnavn med mellomrom/Unicode støttes. Relative lenker går mot dokumentets mappe;
`..` er tillatt etter lokal-viewer-policy. Nettverkslenker, skript og fragmenter
utføres ikke. SaveAs oppdaterer gjeldende historikksti; gamle andre poster beholdes.

Senere korrigering: Denne fasens GUI-test kalte onPointer direkte og beviste
ikke native input-dispatch. Brukerrapporten avdekket en deaktivert FOX-host; se
[regresjon og rettelse](document-links.md) for testen gjennom X11/FOX.
