hendelsesrekkefølge og åpne asynkrone pilspisser. Modellen transporterer fortsatt

## Grenser

Maks åtte fragmentnivåer; aktivitet skal være balansert ved hver grengrense.
Dette er en dokumentert profil, ikke full Mermaid-kompatibilitet.
Lange scenarier kan bli små på én A4-side. Ingen ny sanitizer-kjøring i denne fasen.
Bygg: `cmake --build build -j2`; kontroller: `ctest --test-dir build --output-on-failure`.
