# P3 — Markdown-presentasjon

M1: Implementert cmark-adapter, AST→semantikk, kildeområder, ren block/inline-layout,
UTF-8 wrapping, fontspesifikasjoner, lenketreff og ankergeometri.
M2: FOX-host, fontmåling med glyph-fallback og åpning→preview-pipeline er integrert.

Bevis: `cmake --build build --parallel 4` og `ctest --test-dir build --output-on-failure`:
åtte tester passerer, inkludert InterpreterTest, RendererTest og PresentationTest.
Miljø er GCC 14.3.1, cmark 0.31.1, FOX 1.6.57 og isolert Xvfb.
[Skjermbildet](p3-presentation.png) er visuelt kontrollert. Renderer viser CJK gjennom
installert Droid-fallback; editorens standardfont har bare de glyphs den installerte
editorfonten støtter. Alle UTF-8-bytes bevares også når en font mangler en glyph.

Ingen nettverk/HTML-engine inngår i tolkning eller rendering. .txt bruker ren
tekstmodell; CommonMark HTML er inert. Kodeblokker kan scrolle horisontalt. Lagene
bygger separat; renderer inkluderer ikke FOX/cmark. Transformerte tekstranger
merkes Approximate fremfor å påstå uverifisert eksakt byteplassering.

P3-refresh er ennå synkron. Worker og 300 ms debounce integreres i P4 før dette
regnes som komplett live preview. Full mapping-/scrollakseptanse kontrolleres i P5.
