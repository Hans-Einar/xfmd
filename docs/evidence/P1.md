# P1 — bygg og kontrakter

M1: C++17/CMake/CTest og små, rene kontrakter er implementert. Feil rapporteres som
`xfmd::Error` med ErrorCode; immutable parse-/layoutresultater deles som
`shared_ptr<const ...>`. Dette konkretiserer Result-kontrakten uten et ekstra
Result-bibliotek. FOX- og cmark-typer er ikke offentlige kontrakttyper.

M2: PortContractTest bytter begge porter med uavhengige testimplementasjoner uten
FOX/cmark-linking. LayerBoundaries håndhever include-retningene. CTest brukes med
et minimalt lokalt CHECK-hjelpemiddel i stedet for den foreslåtte Catch2-avhengigheten;
feil har fil/linje og exit-status, også i Release med NDEBUG.

Kommandoer: `cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug`,
`cmake --build build`, `ctest --test-dir build --output-on-failure`.
Miljø: P0-miljø, cmark 0.31.1 bootstrap. PortContractTest, BlueprintStructure og
LayerBoundaries passerer. Applikasjonens composition root lander sammen med konkret
FOX-skall i P2; P1 lager ikke stubs som utgir seg for fungerende applikasjon.
