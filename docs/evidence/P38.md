## Kjente begrensninger

Libavoid kan velge forskjellig gyldig rute ved konkurrerende porter mellom
gjentakelser. Composite state bruker bibliotekets native ruting. Store klasse-/ER-
diagrammer er høye og blir små når de tilpasses én A4-side. Profilene er avgrensede,
ikke full Mermaid-kompatibilitet. Se forfatterveiledningen for avvist syntaks.
