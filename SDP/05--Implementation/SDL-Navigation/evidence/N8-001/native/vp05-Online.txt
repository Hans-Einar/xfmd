Scope and notation
Requires states that an Interface is necessary for a Capability in the selected Mode. It
does not establish sufficiency, a provider, consumption, transport or runtime
execution. Modes have no implicit inheritance. Dashed requires arrows point from
Capability to Interface.
Selected mode: Online. Mode source: Online.
