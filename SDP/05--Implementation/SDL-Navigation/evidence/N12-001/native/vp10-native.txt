Scope and notation
Each packet is one validated fixed Encoding of a Variant in a closed Contract. Bit
offsets are logical contract positions; byte-order and bit-order are explicit source
declarations. The view does not implement serialization or infer padding, variable
lengths, optional-field layout or an executable codec. Header fields belong to the
Contract; variant fields belong to the Variant. Independent Encodings are never
concatenated.
