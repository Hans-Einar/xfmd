Scope and notation
All declared Systems, containers and units form the logical architecture base,
including isolated declarations. Rectangles show the complete structural base with
contains edges. Feature keys annotate logical owners (owns) and selected-mode
containers (allocated-to), derived only through explicit Functionality contribution paths.
Rounded standalone Features have no represented placement. These annotations are
not new direct SDL relations. This is decomposition and responsibility, not an inferred
deployment or call graph.
Selected mode: Online. Only this mode's explicit allocated-to facts inform placement
annotations. Ownership does not imply allocation; missing placement is reported
below.
