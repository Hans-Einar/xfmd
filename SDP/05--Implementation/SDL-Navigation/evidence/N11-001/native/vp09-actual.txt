Scope and notation
Dataset neighborhoods retain explicit from, holds, owns and upholds relations.
Database means a persistent data source, not SQL tables, keys, transactions, a
storage engine or deployment. Unit-held data has no declared persistence. These are
definitions, not runtime instances. Contract completeness is a source assertion, not
execution evidence. Optional fields do not imply null, empty, false or zero. Projections
do not specify executable transformations. Encoding and bit positions belong to VP10.
