## Corrections and limits

Initial native checks exposed a test missing X-server input focus. After fixing
that harness setup, keyboard selection also exposed FOX emitting command events
for Home/arrow keys. The private Favorites list adapter now separates selection
from activation; final native and sanitizer checks cover the corrected behavior.

Ordering uses FOX case-insensitive comparison and a full-path tie-break, not
locale-specific collation. Registry storage follows the existing application
convention: no live cross-process favorites synchronization. The 512-entry limit,
malformed-registry recovery and write-failure feedback are implemented but were
not fault-injected in this native suite. Physical displays and custom font/DPI
combinations are not claimed. No renderer/interpreter change or blanket Verified
status is introduced. Existing SDP sidebar/model proposals remain separate.
