## Delivery and checks

WorkspacePanel places Refresh, Markdown, Up and Open beside Files/Index. Index
hides the latter three controls, retaining the filter. The single Markdown icon
toggle selects .md or all types, intersected with the existing name pattern.
UiButton reuses its checked state and adds an oval Pill role; both button painters
honor that role. IconCatalog draws the adapted public-domain
[Markdown Mark](https://github.com/dcurtis/markdown-mark): M, down arrow and box.
No new class, ownership or pure-layer contract is introduced.

Four targeted native tests passed (20.69 s): PathWorkspaceGuiTest, WorkPathGuiTest,
OpenPathDialogGuiTest and UiControlsTest. They cover mouse and Space toggling,
Markdown-only/all-types plus name filtering, same-row geometry at 1100/640/450 px,
unclipped tabs, Index hide/Files restore with selection retained, Up/root boundary,
shared chooser, both Refresh actions, dirty-buffer preservation, and existing
keyboard/theme control behavior. The five supplemental checks passed (7.64 s):
AppearanceGuiTest, ThemePopupGuiTest, IndexGuiTest, WorkPathTest and BuildVersionTest.
These are nine relevant checks, not a new full-suite claim.

A final test-only change commits dark/classic appearance through PreferencesService
rather than applying just widget colors, so the screenshot also reflects the real
reading palette. Its final rerun passed 1/1 in 20.57 s, recorded in capture-tests.log. This does not
change production code. Visual inspection covers selected and unselected oval
controls in light/dark styles and Index without file controls. Screenshots:
[Files selected](files-header-selected.png), [Files light](files-header-light.png),
[Files dark/classic](files-header-dark.png), [Index](index-header.png).

The initial builds caught two implementation/test wiring omissions (the new
selector declaration and a test calling a private appearance helper); both were
corrected before native acceptance. The final build logs are retained. Blueprint
metadata, symbol, layer, board replay and diff checks are recorded in checks.log.
No new lifetime ownership is introduced, so existing native control and popup
regressions are used without a new sanitizer campaign. Physical monitor trials
and enlarged custom UI fonts are not claimed by these captures.
