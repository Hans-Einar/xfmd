## Native visual review and correction

An initial screenshot exposed a real FOX integration defect despite green tests:
FXFileSelector::acceptButton is a hidden forwarding button, and the added footer
was laid out below the dialog. The corrected dialog packs the selector and footer
inside one vertical frame and uses FOX's visible OK button. NativeInput now rejects
hidden, zero-sized or off-parent click targets. The corrected native chooser and
routing checks both passed; the final regression run uses the corrected library.

Both final 1280×900 screenshots were visually inspected:

- [Open file or folder](open-file-or-folder.png): selected Unicode filename, visible
  file/folder list, OK/Cancel and Open current folder, with no clipped footer.
- [Literal text and independent navigator](text-and-navigator.png): an arbitrary
  text suffix opens in the editor as literal `#` text while navigator and work root remain.
