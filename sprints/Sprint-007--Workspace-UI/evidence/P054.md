## Findings and corrections

The popup needed explicit keyboard ownership for Escape and slider keys, released
when hidden. Refresh originally restored scroll before recomputing the asynchronously
rebuilt tree's scroll range, clamping the offset to zero. PathWorkspaceGuiTest
reproduced that defect; SidebarWidget now lays out the rebuilt tree before restoring
the offset. Both targeted tests pass after correction.
